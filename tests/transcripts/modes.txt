> /help
Console commands (/help <command> for one in full):
  /edit [room|object|character] [{id}]      edit where you are, or what you name
  /play [here]                              play, resuming the game, or from the room edit mode is in
  /new room|character|object {id} [{title}]  make a room, character or object
  /set {key} {value}                        change one field of where you are
  /link {direction} {room}                  add or change an exit from this room
  /unlink {direction}                       remove an exit from this room
  /add {thing} [{room|character|thing}]     put a person or thing here too; scenery if it has no card
  /move {thing} {room|character|thing}      put something somewhere else, or a room in an area
  /state {name} [start] | rename {old} {new} | delete {name}  a state of the thing you're at; makes it a bundle
  /action {verb} {from} --> {to} [with {thing}]  an action from one state to another
  /recipe fixed-until|locked-with|switch|container ...  a common shape, as the commands it stands for
  /save [{name}]                            save the game
  /load [{name}]                            load a saved game
  /reload                                   reload the world from disk, staying where you are
  /restart                                  restart the console on the newest build
  /status                                   the world, where you are, the game, saves and the build
  /map                                      the map around you; the sidebar shows the nearest rooms
  /list {kind}                              every room, character, object or door in the world
  /scope global|area|local                  where /new puts things: global, area or local
  /validate [strict]                        check the world as thwart validate does
  /start                                    play starts in the room you're in
  /write [{name}]                           make a name the world mentions but doesn't define, and open it
  /menu                                     the quick menu for where you are; Ctrl-M opens it too
  /remove {thing}                           delete a thing, room or door and what refers to it, after asking
  /inspect [{thing}]                        a thing in full: its file, where it starts, states, sections, warnings
  /clear                                    empty the output
  /help                                     every command
  /quit                                     leave the console

Edit mode moves through the world as play does:
  north, n, go up, ...  follow an exit from this room
  go <name>             go to a room, area, folder, character or object
  go back               back to where you were;  go /  goes to the world root
  look                  show where you are: a room, a thing, or a folder
  examine <thing>, x    show a person or thing here without going to it

Click a sidebar exit, TO WRITE name or the quick menu to use it. Shift-drag selects text.
