> /help
Console commands, in either mode:
  /edit [name]    edit where you are, or the room or thing named
  /play           switch to play mode, resuming the game
  /play here      play from the room edit mode is in
  /save [name]    save the game (quicksave if no name)
  /load [name]    load a saved game
  /reload         reload the world from disk, staying where you are
  /status         the world, where you are, the game, saves and the build
  /map            the map around you (the sidebar shows the nearest rooms)
  /validate       check the world as thwart validate does, edits included
  /clear          empty the output (the session carries on)
  /restart        restart the console on the newest build, keeping your place
  /help           this list
  /quit           leave the console

Edit mode moves through the world as play does:
  north, n, go up, ...  follow an exit from this room
  go <name>             go to a room, area, folder, character or object
  go back               back to where you were;  go /  goes to the world root
  look                  show where you are: a room, a thing, or a folder
  examine <thing>, x    show a person or thing here without going to it

Changing content (each saves the file):
  /new room <direction> <id> [title]   a room through a new exit from this one
  /new room <id> [title]               a room with no exits, outside a room
  /new character <id> [title]          a character, placed here if in a room
  /new object <id> <type> [title]      an object, placed here if in a room
  /set <key> <value>                   one field; attributes.health 80 sets one entry
  /link <direction> <room>             add or change one exit from this room
  /unlink <direction>                  remove one exit from this room
  /add <thing> [room, character, thing] put a person or thing here too (scenery if no card)
  /move <thing> <room, character, thing> put a person or thing somewhere else
  /state <name> [start]                a state of the thing you're at (makes it a bundle)
  /set <key> <value> in <state>        one field, only while in that state
  /action <verb> <from> --> <to>       an action between states (with <thing>: needs it held)
  /recipe <name> ...                   a common shape: fixed-until, locked-with, switch, container

Full editing, in a full-screen editor (ctrl-s or ⌘s saves, esc closes):
  /edit room [id]                      the room you're in, or the one named
  /edit character [id]                 the character you're in, or the one named
  /edit object [id]                    an object; scenery here gets its card
